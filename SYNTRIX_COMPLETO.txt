================================================================
  1. O QUE E O SYNTRIX
================================================================

O Syntrix NAO e um bot de trading simples. E um sistema operacional
quantitativo modular orientado a eventos, com foco em:

- Contexto: so opera quando o contexto e favoravel
- Filtragem probabilistica: bloqueia operacoes de baixa qualidade
- Gestao de risco: stops, drawdown, cooldown, safe mode
- Observabilidade: logs estruturados, metricas, tracing
- Replay: reproducao completa de sessoes via event sourcing
- Analytics: metricas detalhadas de performance
- Arquitetura desacoplada: modulos independentes via EventBus

Filosofia central:
"Selecionar melhor e mais importante do que prever melhor."

O sistema opera pouco, evita contexto ruim, prioriza sobrevivencia
estatistica e registra tudo para auditoria.

  2. ARQUIVOS E COMO RODAR
================================================================

ARQUIVOS PRINCIPAIS:
  - start.py        Launcher principal (menu com todos os botoes)
  - login.py        Tela de login IQ Option (email, senha, saldos)
  - main.py         Sistema Syntrix (motor de trading)
  - instalar.bat    Instalacao automatica de dependencias (Windows)
  - iq_api.py       Loader centralizado da API IQ Option

COMO INSTALAR (primeira vez):
  1. Extrair os arquivos na pasta desejada
  2. Dar dois cliques no "instalar.bat"
     OU rodar no terminal:
     pip install pyyaml fake_useragent
     pip install git+https://github.com/zagmi/iqbroker.git

COMO RODAR:
  python start.py              Abre o launcher com menu completo
  python login.py              Abre tela de login IQ Option
  python main.py               Roda com interface Tkinter
  python main.py --headless    Roda sem interface (so terminal)
  python main.py --interval 30 Muda intervalo de scan (padrao 60s)
  python main.py --profile moderado   Usa perfil moderado

TESTES:
  python -m pytest tests/ -v   Roda os 72 testes unitarios

================================================================
  4. MAQUINA DE ESTADOS (8 estados)
================================================================

  IDLE            Sistema ocioso, aguardando inicio
  SCANNING        Escaneando ativos configurados
  WAITING_CONTEXT Avaliando contexto de um ativo
  READY           Contexto aprovado, avaliando estrategias
  EXECUTING       Executando trade no broker
  COOLDOWN        Pausa apos trade executado
  RISK_LOCK       Bloqueado por limites de risco
  SAFE_MODE       Modo seguro ativado apos perdas consecutivas

Fluxo normal:
  IDLE -> SCANNING -> WAITING_CONTEXT -> READY -> EXECUTING -> COOLDOWN -> SCANNING


================================================================
  5. CONTEXT GATE — 11 VERIFICACOES
================================================================

O ContextGate e o filtro central. Padrao: BLOCK.
So libera quando TODAS as verificacoes passam.

  1. Payout minimo         Payout do ativo >= threshold (65% no leve)
  2. Sessao valida          Horario dentro de sessao ativa
                            OTC: sempre permitido (24h)
                            Regular: London (07-16), NY (13-22), Overlap (13-16)
  3. Filtro de noticias     Bloqueia proximo de noticias economicas
  4. Regime de mercado      Bloqueia regimes instáveis
  5. Detector de spikes     Bloqueia candles anomalos
  6. Latencia do broker     Bloqueia se latencia > threshold
  7. Cooldown               Respeita tempo minimo entre trades
  8. Rate limit             Max trades por hora
  9. Drawdown               Bloqueia se drawdown > threshold
 10. Saude do broker        Verifica conexao ativa
 11. Checks customizados    Extensivel para novas verificacoes

Retornos possiveis:
  ALLOW   — todas as verificacoes passaram
  CAUTION — avisos mas sem bloqueio duro
  BLOCK   — uma ou mais verificacoes falharam

================================================================
  7. ESTRATEGIAS DE TRADING
================================================================

  1. TREND PULLBACK (trend_pullback.py)
     - Opera a favor da tendencia durante pullbacks
     - Regime compativel: trend
     - Usa EMA, RSI, ATR para confirmar

  2. RANGE REVERSAL (range_reversal.py)
     - Opera reversao em mercado lateral
     - Regime compativel: range
     - Usa Bollinger Bands, RSI, Stochastic

  3. BREAKOUT (breakout.py)
     - Opera rompimentos de niveis importantes
     - Regime compativel: range, low_volatility
     - Usa ATR, volume, suporte/resistencia

  4. MOMENTUM (momentum.py)
     - Opera movimentos fortes de momentum
     - Regime compativel: trend, high_volatility
     - Usa MACD, ADX, RSI

Cada estrategia:
  - Retorna score (0.0 a 1.0)
  - Retorna confianca
  - Retorna direcao (CALL/PUT)
  - NUNCA executa ordem diretamente
  - E avaliada pelo ScoringEngine antes de executar

  2. EMA   — Exponential Moving Average
  3. RSI   — Relative Strength Index

  5. ATR   — Average True Range
  6. MACD  — Moving Average Convergence Divergence

  8. ADX   — Average Directional Index

Todos implementados em Python puro (sem NumPy, sem pandas).

  - Drawdown maximo
  - Profit Factor
  - Edge esperado vs real
  - Performance por regime de mercado
  - Performance por sessao

  Cada trade tem 40+ campos incluindo:
    ativo, payout, score, regime, sessao, perfil,

    latencia, resultado, motivo de bloqueio


================================================================
  14. WATCHDOG (monitoramento)
================================================================

O Watchdog monitora continuamente:
  - Threads travadas
  - Conexao perdida com broker
  - Atraso na fila de eventos
  - Queue overflow
  - Handlers lentos (>1s de processamento)
  - Freeze da interface
  - Status do websocket
  - Intervalo de checagem: 10 segundos
